## 自选输入与结果
输入：[0, -2, 0, -2, 5]
预期和实际相同：
unique = [0, -2, 5]
counts = {0: 2, -2: 2, 5: 1}
repeated = {0, -2}

追踪 -2：首次遇到加入 unique，计数从 0 增到 1；再次遇到只增加计数到 2，因此进入 repeated。输入保持不变，每次调用新建结果容器。
边界：空输入返回空列表、空字典、空集合；零与负数同样参与统计。

## 基础题断言说明
自选输入 [0, 3, 3, -1]，positive_squares 返回 [9, 9]。
断言比较实际结果与手工预期：只保留两个正数 3，平方各为 9，顺序和重复保留，0 不保留。
另一条断言检查原列表仍为 [0, 3, 3, -1]，确认输入没有改变。
pop_last 是三题中需要修改原列表的函数：删除末项并返回它；空列表返回 None。
